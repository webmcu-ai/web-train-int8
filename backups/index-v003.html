Vision CNN INT8 SD trainerv003

Browser companion for the XIAO ESP32-S3 vision firmware (firmware-v003): load the SD card, add images, review and clean them, train the same CNN in float, convert it to INT8, then save both models back to the card. The page and the device can each train, convert and run either model, so you can switch and compare. A model made on the device (Train FLOAT, Convert to INT8) loads here the same way.

Everything runs in this page. Images and weights never leave your computer.

3 Train

Model layout

These are compile-time settings in the sketch (INPUT_SIZE, CONV1_FILTERS, CONV2_FILTERS). Copy the lines from section 2 into the sketch after changing them. The 3x3 kernel is fixed in the firmware loops. Images on the card stay 240x240, so changing the size needs no new photos, only a retrain. The size must be even because of the 2x2 max pool. Cost grows with the square of the input size, in the browser and on the device.

4b Convert to INT8

Post-training quantization: weights are int8 per filter, activations are int8 per layer (ranges measured on the calibration images), biases and sums are int32. Save writes header/myWeightsInt8.bin (the device loads it at boot), header/myWeightsInt8.h (to bake into the sketch) and config.json. The file also holds one test image and its expected INT8 logits, so the device can check itself at boot. The float model stays in header/myWeights.bin. Both files load back from the SD card when you open the folder or zip, so the two models are always available together. Retraining discards the INT8 model, because it was made from the old float weights.

6 Save

SD folder mode: the existing weights file is copied to myWeights.bin.bak first, then the new one is written. A config.json with the class names and layout is written next to it. The firmware reads the class names from it at boot. NUM_CLASSES, INPUT_SIZE and the filter counts always come from the compiled sketch.
Zip mode: Save weights keeps the model for the zip. Save .zip downloads header/myWeights.bin (and images if ticked) in the SD card layout.
